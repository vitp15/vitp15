## Work

**Colete-Online** (Sep 2025 – present), full-stack engineer. Shipping modules for WooCommerce, PrestaShop, Magento 2 and OpenCart and the PHP library they share; checkout features end to end (pickup points and lockers on a map, address autocomplete, cash on delivery, AWB generation, multi-currency); the TypeScript platform behind them (public API, Prisma and MySQL, Redis, payments); CI/CD with Playwright suites, PHPStan, Trivy and self-hosted runners; a parcel-locker scanning prototype in Python (camera, laser measurement, motion control).

**BBMM Software** (Apr – Sep 2025), software engineer in a five-person team building a web product for GoAhead Venture, a US client: React, FastAPI, SQL, CI/CD.

**Freelance** (2024 – 2025): Sona, an Android app that detects car malfunctions from engine sound with an ML server on Google Cloud; Biblia Noul Testament audio for Android and iOS.

BSc in Computer Science, Politehnica Bucharest, 2022 – 2026.
